
# Disk Usage

Uma extensão para GNOME Shell que exibe o uso e o espaço livre dos discos conectados diretamente no painel superior.

**Recursos**
* Monitoramento atualizado ao clicar no menu.
* Suporte a novos discos e pendrives montados.
* Reordenação personalizada e permanente via janela de preferências.

-------------------------------------------------------------------------------------------------------------------------

A GNOME Shell extension that displays the usage and free space of connected disks directly in the top panel.

**Features**

* Real-time monitoring updated on menu click.
* Support for newly mounted disks and USB drives.
* Custom and permanent reordering via the preferences window.
